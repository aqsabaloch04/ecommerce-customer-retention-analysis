# E-commerce Customer Retention Analysis

## Project Overview

This project analyzes transactional sales data to derive key business performance metrics and customer retention insights.

The project includes data preprocessing, RFM (Recency, Frequency, Monetary) customer segmentation, and an interactive Streamlit dashboard.

## Key Features

* Data cleaning and preprocessing using Pandas
* Handling missing values and data types
* Filtering returned orders
* Monthly revenue analysis
* RFM customer analysis
* Customer segmentation into:

  * Champions
  * Regular
  * Churned
* Interactive Streamlit dashboard
* Date-based filtering
* Customer retention analysis

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit
* Excel

## Installation

Install the required Python libraries using:

```bash
pip install pandas numpy matplotlib streamlit openpyxl
```

## Run the Dashboard

Open the project folder in Command Prompt and run:

```bash
python -m streamlit run app.py
```

The Streamlit dashboard will then open in your web browser.

## Project Files

* `app.py` — Streamlit dashboard application
* `Ecommerce_Customer_Retention_Analysis.ipynb` — Data analysis and RFM analysis notebook
* `rfm_data.csv` — Processed RFM customer data

## Dataset

The analysis is based on an e-commerce transactional sales dataset containing more than 100,000 sales records.

The original Excel dataset is not included in the GitHub repository because of its large file size.
